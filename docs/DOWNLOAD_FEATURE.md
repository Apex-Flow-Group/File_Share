# 📥 ميزة تحميل الملفات من الشبكة

## 🎯 الميزة الجديدة

الآن يمكنك **تحميل** أي ملف موسيقى من جهاز آخر على الشبكة وحفظه على جهازك!

---

## 🆚 الفرق بين Streaming و Download

### 🎵 Streaming (البث المباشر)
```
✅ تشغيل فوري
✅ لا يستهلك مساحة
❌ يحتاج WiFi طول الوقت
❌ لا يمكن الاستماع بدون شبكة
```

### 📥 Download (التحميل)
```
✅ يحفظ الملف على جهازك
✅ يمكن الاستماع بدون شبكة
✅ يمكن مشاركته مع الآخرين
❌ يستهلك مساحة
❌ يأخذ وقت للتحميل
```

---

## 📱 كيف تستخدم الميزة؟

### الخطوات:

#### 1️⃣ تصفح موسيقى جهاز آخر
```
1. افتح Music من القائمة الجانبية
2. اضغط على جهاز من قائمة "🌐 Nearby Devices"
3. ستظهر قائمة الموسيقى من الجهاز الآخر
```

#### 2️⃣ تحميل أغنية
```
1. اضغط على أيقونة "⋮" بجانب أي أغنية
2. ستظهر قائمة خيارات:
   ▶️ تشغيل
   🎵 إضافة للقائمة
   📥 تحميل الملف  ← جديد!
3. اضغط على "تحميل الملف"
```

#### 3️⃣ طلب الموافقة
```
1. سيُرسل طلب للجهاز الآخر
2. صاحب الجهاز يوافق أو يرفض
3. إذا وافق، يبدأ التحميل تلقائياً
```

#### 4️⃣ بعد التحميل
```
✅ الملف محفوظ في مجلد Music
✅ يمكنك الاستماع بدون شبكة
✅ يظهر في قائمة الأغاني المحلية
```

## 🎓 التفاصيل التقنية

### 1. الكود في `music_tab_pro.dart`:

```dart
// عند الضغط على "تحميل"
Future<void> _downloadTrack(MediaItem track) async {
  // 1. إيجاد الجهاز المصدر
  final device = widget.devices.firstWhere(
    (d) => d.ip == track.deviceId,
  );
  
  // 2. استخدام نظام الإرسال الموجود (مع طلب موافقة)
  final success = await ApexCore.instance.sendFile(track.path, device);
  
  // 3. إظهار نتيجة
  if (success) {
    // ✅ تم التحميل بنجاح
  }
}
```

### 2. نظام الموافقة (موجود مسبقاً):

```dart
// في apex_core.dart
Future<bool> sendFile(String filePath, Device targetDevice) async {
  // 1. طلب موافقة من الجهاز المستقبل
  if (!await _requestPermission(targetDevice, fileName)) {
    return false; // رفض الطلب
  }
  
  // 2. إرسال الملف
  await _uploadFile(filePath, targetDevice);
  
  return true;
}
```

## 💡 مميزات الميزة

### ✅ الأمان:
- يطلب موافقة صاحب الجهاز
- لا يمكن التحميل بدون إذن
- يظهر اسم الملف والحجم

### ✅ السهولة:
- زر واحد فقط "تحميل"
- يعمل تلقائياً
- يحفظ في مجلد Music

### ✅ الذكاء:
- يستخدم نظام الإرسال الموجود
- يظهر progress bar
- يدعم الملفات الكبيرة

## 🐛 حل المشاكل

### ❌ لا يظهر خيار "تحميل"؟
```
✅ تأكد أن الأغنية من جهاز آخر (وليست محلية)
✅ الخيار يظهر فقط للملفات البعيدة
```

### ❌ فشل التحميل؟
```
✅ تأكد من اتصال WiFi
✅ تأكد من موافقة صاحب الجهاز
✅ تحقق من المساحة المتوفرة
```

### ❌ أين الملف المحمّل؟
```
✅ في مجلد: /storage/emulated/0/Music
✅ يظهر في تبويب "الأغاني" المحلية
✅ يمكن تشغيله بدون شبكة
```

## 🎯 حالات الاستخدام

```
- تتصفح موسيقى أصدقائك
- تحمّل الأغاني المفضلة
- تبني مكتبتك الخاصة
```

### 3. مشاركة الموسيقى:
```
- تحمّل أغنية من جهاز A
- تصبح متوفرة على جهازك
- يمكن لجهاز B تحميلها منك
```
